# 인증번호 전달기 (OtpForwarder)

세컨드 폰(갤럭시 A36 · Android 16 · One UI 8.5)으로 오는 **문자(SMS)**와 **카카오톡 알림**을
읽어서 **텔레그램 봇**으로 전달하는 안드로이드 앱입니다.

## 동작 방식
- 문자: `RECEIVE_SMS` 권한으로 수신 브로드캐스트를 직접 받습니다. (가장 안정적)
- 카카오톡: 공식 API가 없어 **알림 접근 권한(NotificationListenerService)**으로 알림 내용을 읽습니다.
- 전송: 텔레그램 Bot API `sendMessage`를 HTTPS로 호출합니다.
- 전송 실패분은 기기 내 큐에 저장했다가 네트워크 복구 시 자동 재전송합니다. (24시간 경과분은 폐기)

## 사전 준비 — 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather** 검색 → `/newbot` → 이름·사용자명 입력 → **봇 토큰** 받기
   (형식: `123456789:ABCdef...`)
2. 방금 만든 봇과 대화방을 연 뒤 아무 메시지나 보냅니다.
3. **챗 ID** 확인: 브라우저에서
   `https://api.telegram.org/bot<봇토큰>/getUpdates` 를 열면 `"chat":{"id":123456789}` 가 보입니다.
   그 숫자가 챗 ID입니다. (또는 @userinfobot 에게 말을 걸면 알려줍니다)

## 앱 설치·설정 순서 (세컨드 폰에서)
1. APK를 설치합니다. (출처를 모르는 앱 설치 허용 필요)
2. 앱 실행 → **봇 토큰**, **챗 ID** 입력 → **저장**.
3. **1) 문자 수신 권한 허용** 버튼 → 권한 허용.
4. **2) 알림 접근 허용 (카톡)** 버튼 → 목록에서 "인증번호 전달기" 켜기.
5. **3) 배터리 최적화 제외** 버튼 → 허용. (삼성 절전으로 앱이 죽는 것 방지)
6. **테스트 전송** 버튼으로 텔레그램 수신 확인.

### ⚠ Android 16 / 사이드로드 앱 주의
- 직접 설치(APK)한 앱은 알림 접근 권한이 처음에 막혀 있습니다.
  **설정 → 앱 → 인증번호 전달기 → 우측 상단 ⋮ → "제한된 설정 허용"**을 먼저 눌러야
  알림 접근을 켤 수 있습니다.
- 최근 Android는 인증번호가 든 알림을 일반 알림 리스너에게 가릴 수 있습니다.
  **문자(SMS) 직접 수신은 영향 없음**, 카톡 알림은 기기 상태에 따라 번호가 가려질 수 있어
  실제 기기에서 확인이 필요합니다.

## 보안 메모
- 봇 토큰·챗 ID는 기기 내부(SharedPreferences)에만 저장됩니다.
- 텔레그램 봇 대화는 종단간 암호화가 아닙니다. 인증번호를 외부로 보내는 일이므로 리스크를 알고 쓰세요.
- 봇은 설정한 챗 ID 한 곳으로만 전송합니다.
